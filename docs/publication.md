# 公开源码范围

此仓库采用脱敏的源码快照，不附带开发者机器上的运行状态或历史仓库数据。

## 包含

- 应用源码、自动化测试、依赖清单与锁文件。
- 通用本机配置示例和启动入口。
- 与项目状态、使用边界有关的公开说明。
- 不读取或输出配置内容的 Windows 只读文件保护辅助脚本。

## 排除

- 数据库、备份、模型会话、账号、任务产物与工作区文件。
- 本机环境文件、真实配置、凭据、代理设置与用户目录信息。
- 原始调试脚本、真实业务项目验证记录、内部地址、会话标识及截图。
- 依赖目录、编译产物、工具缓存和本机自动化目录。

公开源码中的测试数据只用于合成场景，并不代表真实账号或线上配置。软件包锁文件指向公开 npm registry。

## 后续发布检查

1. 检查 `git status` 和暂存文件列表，避免使用未审查的全目录添加。
2. 检查代码、文档、图片和 Git 历史中的密钥、内网地址、个人路径与真实业务标识。
3. 运行类型检查、测试与构建；不得把 mock 通过描述为真实工具链验收。
4. 使用 GitHub 隐私邮箱提交；上传前确认仓库归属与可见性。
5. 发现泄露时先撤销凭据，再处理仓库历史，不假定删除文件就能撤回公开内容。
